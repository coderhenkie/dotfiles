### 0. Instructions for AI Assistants (read first)
- **Passwordless sudo is a VM-only testing convenience. NEVER integrate it into the setup.** The development VM has `/etc/sudoers.d/99-sudo-nopasswd` (`%sudo ALL=(ALL:ALL) NOPASSWD: ALL`) so AI assistants can install packages and test changes without a password prompt.
- Never add `NOPASSWD`, files in `/etc/sudoers.d/`, `visudo` edits, or any other sudo/privilege changes to `setup.sh`, `scripts/`, or any other tracked file. `setup.sh` must keep using plain `sudo` so a real machine always asks for the password.
- Do not assume passwordless sudo exists on other machines; scripts must work (and fail safely) when `sudo` prompts for a password.

### 1. Project Goal
A bulletproof, 100% reproducible dotfiles setup for Debian 13 (Trixie) with the i3 window manager. With a single command (`setup.sh`), a minimal Debian installation is transformed into a fully configured, keyboard-driven environment (Vim-style) powered by a central dynamic Color Engine.

### 2. Installed Applications: What, Where & Why
Most software is installed via the `setup.sh` script using `nala` (standard `/usr/bin/`). Specific tools have dedicated locations:

*   **Package Management & Base**: `nala` (faster apt frontend with parallel downloads), `curl`, `git`, `wget`, `unzip`, `jq`, `psmisc`, and `unattended-upgrades` (daily automatic Debian security & point-release updates via `/etc/apt/apt.conf.d/20auto-upgrades`).
*   **Display & Window Manager**: `xserver-xorg`, `xinit`, `lightdm` & `lightdm-gtk-greeter` (login manager), `light-locker` (screen locker), `i3` (tiling window manager), `picom` (compositor for transparency, shadows, and rounded corners).
*   **Core Desktop Apps**:
    *   `kitty`: Fast, GPU-accelerated terminal.
    *   `thunar`: Lightweight GTK3 file manager.
    *   `polybar`: Modular dual status bar (top & bottom).
    *   `rofi`: Application launcher and interactive menu engine for theme selection, wallpaper picking, and live hotkey management.
*   **Desktop Essentials** (`setup.sh` section 3.5):
    *   `network-manager` & `network-manager-gnome`: Wi-Fi/VPN management through the Polybar wifi module (left-click opens the Rofi network menu `scripts/menu-wifi.sh`, right-click opens `nmtui`; `nm-connection-editor` for advanced settings); the `nm-applet` tray icon is disabled. Interfaces listed in `/etc/network/interfaces` (e.g. the installer's wired/SSH config) stay with ifupdown and are left untouched; `setup.sh` only prints a hint when Wi-Fi is configured there.
    *   `mate-polkit`: Polkit agent (`/usr/libexec/polkit-mate-authentication-agent-1`, started by i3) so GUI apps can ask for the admin password (Thunar mounts, Timeshift). Replaces the auto-installed `ukui-polkit`, which never starts outside UKUI/MATE.
    *   `zathura` (+ `zathura-pdf-poppler`), `imv`, `mpv`: PDF viewer (vim keys, Color Engine themed), image viewer, and audio/video player, set as defaults by `scripts/default-apps.sh`.
    *   `thunar-archive-plugin` & `xarchiver`: "Extract here" / "Create archive" in Thunar. `gvfs-backends`: phones (MTP), SMB/SFTP shares and trash support in Thunar.
    *   `qalc`, `xdotool`, `unicode-data`, `fonts-noto-color-emoji`: Back-ends for the Rofi calculator and emoji picker.
    *   `autorandr` & `arandr`: Saved monitor profiles that switch automatically on plug/unplug (`autorandr --save <name>`), plus a GUI to arrange screens.
    *   `timeshift`: System snapshots (configure the snapshot location in its GUI; mind the free disk space).
    *   `earlyoom` & `zram-tools`: Low-memory protection: zstd-compressed swap in RAM (50%) and earlyoom, which kills the biggest Thorium/Obsidian/Spotify process before the desktop freezes.
    *   Hardware-dependent (auto-detected by `setup.sh`): `tlp` only when a battery exists (`/sys/class/power_supply/BAT*`), `bluez` & `blueman` only when a Bluetooth controller exists (`/sys/class/bluetooth` or a USB class `e0/01/01` interface), `fwupd` only on bare metal (`systemd-detect-virt`).
*   **Theming & System Tools**:
    *   `feh`: Lightweight image viewer used exclusively to set desktop wallpapers.
    *   `fastfetch` & `btop`: Modern system information and resource monitoring in the terminal.
    *   `starship`: Bash prompt (Debian package), colored by the Color Engine (see `starship/` in section 4).
    *   **CLI tools** (Debian packages, see `cli/` in section 4): `fzf` (fuzzy finder), `ripgrep` (`rg`), `fd-find` & `bat` (Debian names them `fdfind`/`batcat`; `setup.sh` links them as `fd`/`bat` in `~/.local/bin`), `zoxide` (`z`).
    *   `dunst` & `libnotify-bin`: Minimal bottom-right notification popups (`dunst/dunstrc`), recolored live by the Color Engine.
    *   `yad`: GTK calendar popup opened by clicking the Polybar clock (`scripts/calendar.sh`).
    *   `maim` & `xclip`: Area screenshots (`scripts/screenshot.sh`) saved to `~/Pictures` and copied to the clipboard.
    *   `fontconfig` & **Font modules** (`fonts/*.font`): one font for the whole desktop, switchable with the Rofi font picker (`$mod+Shift+f`, `scripts/menu-font.sh`). Modules: Iosevka (default) and JetBrains Mono (the two original fonts) plus the five most-recommended Nerd Fonts: Fira Code, Hack, Meslo, Cascadia Code (CaskaydiaCove) and Source Code Pro (SauceCodePro). Each module is a small file (name, description, `ryanoasis/nerd-fonts` `.tar.xz` asset, file prefix, UI family + Mono family); adding a font means adding one `.font` file. `setup.sh` downloads every font module up front (checksum-verified), so switching fonts is instant; it keeps only Regular/Bold/Italic/BoldItalic of the `Nerd Font` (UI) and `Nerd Font Mono` (Kitty) variants, into `/usr/local/share/fonts/ColorEngine/<id>` (user-owned, so the picker needs no sudo and the LightDM greeter can read it). `fontconfig/fonts.conf` (symlinked to `~/.config/fontconfig`) includes the generated `~/.cache/theme/fonts.conf`, which makes the active font the default for `sans-serif`, `serif` and `monospace` and maps common web fonts (Arial, Helvetica, Roboto, Times New Roman, Courier New, ...) to it.
*   **Custom Installations (Outside APT)**:
    *   `Neovim`: Installed as an AppImage in `~/appimages/nvim.appimage` with a symlink to `~/.local/bin/nvim` (requires `libfuse2` and `fuse`) to ensure a modern release independent of Debian's release cycle. Every `setup.sh` run compares `nvim --version` with the newest GitHub release and updates it (checksum-verified) when a newer one exists.
    *   `Obsidian`: Latest x86_64 AppImage fetched automatically via the GitHub API (`jq`), placed in `~/appimages/obsidian.appimage` (`obsidian-app` starts it; `obsidian` opens today's note in Neovim), its icons in `~/.local/share/icons`, the `obsidian://` link handler, and a `.desktop` entry (without `--no-sandbox`; Electron's sandbox works on Debian 13) in `~/.local/share/applications/obsidian.desktop` for Rofi.
    *   `Thorium Browser`: High-performance Chromium fork installed and kept up to date by `scripts/update-thorium.sh` (`AVX2` or `SSE4` based on `/proc/cpuinfo` detection) into `~/appimages/thorium.appimage` (installed version in `~/appimages/thorium.version`). It picks the newest build from the official `Alex313031/Thorium` repo (Linux builds stalled at M138) or the collaborator builds in `gz83/thorium` (linked from the official release notes), verifies the SHA-256, and runs from `setup.sh` and at every i3 login, symlinked to `~/.local/bin/thorium` with a `.desktop` entry (no `--no-sandbox`: Debian 13 allows unprivileged user namespaces, so Chromium's sandbox works inside the AppImage) in `~/.local/share/applications/thorium.desktop` for Rofi. Configured with automatic installation of 4 Chrome Web Store extensions (`Thorium Material Dark Theme`, `Bitwarden`, `Ghostery`, and `Vimium`) and GTK+ Color Engine integration. Its default web fonts (standard, sans-serif, serif, fixed) are set to the generic families `sans-serif`/`serif`/`monospace` in `Default/Preferences` (only while Thorium is closed), so web pages follow the active font through fontconfig; pages that ship their own web fonts keep those.
    *   `Herdr`: Installed via `https://herdr.dev/install.sh`.
    *   `Antigravity CLI`: Installed via `curl -fsSL https://antigravity.google/cli/install.sh | bash`.
    *   `Pywal`: AI color extractor installed in a dedicated Python virtual environment (`~/.local/pywal-venv`) via `pip` (with `python3-pip`, `python3-venv`, `imagemagick`), symlinked to `~/.local/bin/wal`; `setup.sh` runs `pip install --upgrade pip pywal` so re-runs keep it current.

### 3. Architecture & Directory Structure
- **Master Repo (`~/dotfiles`)**: Contains all static configurations, 15 curated wallpapers (`wallpapers/`), preset themes (`themes/`), and Bash scripts (`scripts/`). Managed via Git. The master `setup.sh` script updates to the latest `origin/main` (hard reset) before applying configurations. When the repo has uncommitted changes or unpushed commits it lists them first and asks (j/k or arrows, Enter) whether to save them (stash + `setup-backup-<date>` branch), discard them, skip the update, or abort; without a terminal it saves them. Re-runs keep the active Color Engine palette (`~/.cache/theme/current.theme`); Dracula is only the fresh-install default.
- **Symlinks (`~/.config/`)**: Directories for `i3`, `kitty`, `polybar`, `feh`, `rofi`, `nvim`, `picom`, `btop`, `dunst`, `zathura`, and `autorandr` are symlinked directly to `~/dotfiles/` by `setup.sh` (empty directories `nvim` and `feh` are tracked via `.gitkeep`).
- **Dynamic Cache (`~/.cache/theme/`)**: To keep the Git repository clean, tracked dotfiles contain NO hardcoded colors. All applications source or import their active colors from generated files inside `~/.cache/theme/`.

### 4. Dotfiles & Specific Configuration Details
To support the dynamic Color Engine and smooth workflow, the following configurations are in place:
- **i3 (`i3/config`, `i3/hotkeys.default` & `i3/hotkeys.conf`)**:
  - `i3/config` contains static window manager settings, appearance, and autostart commands, and includes `~/.config/i3/hotkeys.conf` alongside `~/.cache/theme/i3.conf`.
  - `i3/hotkeys.default` (tracked in Git) stores the default blueprint for `$mod` (`Mod1` Alt), `bindsym` shortcuts, and `mode "resize"`. On first install (`setup.sh` or first launch of `menu-hotkeys.sh` / `toggle-modkey.sh`), it is copied once to `i3/hotkeys.conf` if `hotkeys.conf` does not exist yet.
  - `i3/hotkeys.conf` is ignored by Git via `i3/.gitignore` so each machine (VM vs. baremetal) can customize its own `$mod` key (`Mod1` Alt or `Mod4` Super/Win) and hotkeys without ever causing `git pull` merge conflicts.
  - Window borders (`3px` pixel border) and subtle window gaps (`gaps inner 4`, `gaps outer 1`).
  - CapsLock and Escape are swapped via `setxkbmap -option caps:swapescape`.
  - Runs `light-locker` (`--lock-after-screensaver=5 --no-late-locking --lock-on-suspend`) with a 3-minute X11 idle lock timer (175s screensaver + 5s light-locker grace) while keeping DPMS monitor power-off disabled (`xset s 175 5 -dpms`) to prevent VM lock freezes.
  - Restores the last selected wallpaper via `exec_always --no-startup-id ~/.fehbg`.
  - Custom keybindings: `$mod+t` for the AI wallpaper theme generator (`scripts/menu-wallpaper.sh`), `$mod+Shift+w` for the preset theme selector (`scripts/menu-theme.sh`), `$mod+m` for the interactive Rofi Hotkey Menu (`scripts/menu-hotkeys.sh`), `$mod+Shift+x` for locking the screen (`scripts/lock.sh`), `$mod+p` for the screen menu (mirror / extend, `scripts/menu-monitors.sh`), `$mod+Shift+s` for an area screenshot (`scripts/screenshot.sh`), `$mod+n` / `$mod+Shift+n` for silent mode and the notification menu (`scripts/menu-notifications.sh`), `$mod+c` for clipboard history (`scripts/menu-clipboard.sh`), `$mod+equal` for the calculator (`scripts/menu-calc.sh`), `$mod+Shift+period` for the emoji picker (`scripts/menu-emoji.sh`), `$mod+Shift+f` for the font picker (`scripts/menu-font.sh`), and `$mod+Shift+e` for the power menu (`scripts/menu-power.sh`, replaces the old `i3-nagbar` exit prompt).
- **LightDM GTK Greeter & `light-locker` (`scripts/lock.sh` & `/etc/lightdm/lightdm-gtk-greeter.conf`)**:
  - `setup.sh` configures `/etc/lightdm/lightdm-gtk-greeter.conf` with `theme-name=ColorEngine`, `icon-theme-name=ColorEngine`, `font-name=Sans 10` (the font family comes from the generated `gtk.css`, so the greeter follows the font picker), `background=/usr/share/themes/ColorEngine/wallpaper`, and `screensaver-timeout=0`, plus `/etc/lightdm/lightdm.conf.d/50-color-engine.conf` (`setxkbmap -option caps:swapescape`).
  - `/usr/share/themes/ColorEngine` and `/usr/share/icons/ColorEngine` are owned by `$USER` with world-readable (`755`/`644`) permissions so `scripts/apply-theme.sh` and `scripts/lock.sh` can update the lock/login screen GTK3 CSS (`#panel_window`, `#login_window`, `#power_window`, `#prompt_entry`, `#login_button`, `3px` accent border, `4px` corner radius), dynamic folder/status icons, and active `feh` wallpaper (`~/.fehbg`) live in user-space without requiring `sudo`.
- **Picom (`picom/picom.conf`)**:
  - Uses the fast `xrender` backend with `vsync = true`, rounded corners (`corner-radius = 4`, excluding docks and Polybar), and window shadows (excluding Polybar).
  - Opacity settings: `inactive-opacity = 1.0`, `active-opacity = 1.0`, and per-application `opacity-rule` keeping Rofi and Polybar at `100%`, Kitty and Thunar at `95%`, Obsidian at `98%`, and Thorium (`thorium`, `Thorium`, `thorium-browser`) at `100%` (window opacity applies to the whole window, so photos on websites would show the wallpaper too).
- **Obsidian theme (`obsidian/colorengine/`, plugin `ColorEngine`)**: Obsidian follows the desktop theme and font without touching Obsidian Sync. `apply-theme.sh` writes `~/.cache/theme/obsidian.css` (outside the vault, so it never syncs) using only Obsidian's built-in CSS variables (base scale, accent, headings, named colors, `--font-*-override`). The plugin reads that file live and, while active, switches the vault's community theme off *in memory only* (it never calls `setTheme`, so `appearance.json` is untouched) and forces dark mode on this machine. So it works the same whatever community theme is selected, and other devices keep the synced one. Where the file is missing (phone, Windows, machines without the dotfiles) the plugin does nothing; it is `isDesktopOnly`. Command palette: *ColorEngine: Toggle desktop theme* (remembered per machine in `localStorage`, not synced). Install/update it into a vault with `scripts/obsidian-colorengine.sh` (copies, because Sync doesn't follow symlinks; Sync then spreads it to the other devices).
- **Polybar (`polybar/config.ini` & `polybar/launch.sh`)**:
  - Dual-bar layout (`bar/top` and `bar/bottom`) launched cleanly via `setsid` in `polybar/launch.sh`, sourcing colors from `~/.cache/theme/polybar.ini`.
  - **Top Bar (`bar/top`)**: Displays i3 workspaces (with `5px` padding and `1px` margin spacing), active window title (`xwindow`), date/time, and system tray. The clock is clickable: a click toggles a calendar popup (`scripts/calendar.sh`).
  - **Bottom Bar (`bar/bottom`)**: Live system telemetry modules:
    - `filesystem`: Queries real mounted filesystems every 5s via `scripts/polybar-disk.sh` (`df -B1 --total` (excluding `tmpfs`, `devtmpfs`, `efivarfs`, `squashfs`, `overlay`), displaying `%used (used GB/total GB)`.
    - `network`: Universal local IPv4 detection every 3s via `scripts/polybar-ip.sh` (`ip -4 route get 1.1.1.1` (with `hostname -I` fallback), supporting both Wi-Fi and wired Ethernet interfaces on baremetal and VMs.
    - `cpu` & `memory`: Live CPU load and RAM usage; RAM via `scripts/polybar-memory.sh` (`used% (used GB)`, MemTotal − MemAvailable, same GB units as the disk module).
    - `gpu` (`scripts/polybar-gpu.sh`): Multi-vendor GPU load monitor supporting NVIDIA (`nvidia-smi`), AMD (`gpu_busy_percent`), and Intel (`i915`/`xe` via RC6 idle residency delta and frequency scaling), using `systemd-detect-virt --vm` so `0% (VM)` is only shown inside virtual machines and `0%` on idle baremetal.
    - `notifications` (`scripts/menu-notifications.sh status`): Bell icon only (crossed-out bell in silent mode, plus the number of held notifications when there are any); left-click toggles silent mode, right-click opens the notification menu.
    - `pulseaudio` & `battery`: Volume status (scrolling steps 5%, same as the volume keys in `i3/hotkeys.default`) and battery capacity/status (`scripts/polybar-battery.sh`; hidden on machines without a battery).
    - `wifi` (`scripts/polybar-net.sh`): cable icon + `Wired` when ethernet is up, otherwise Wi-Fi signal + SSID (muted icon when disconnected); left-click opens `scripts/menu-wifi.sh`, right-click `nmtui`.

  - `obsidian-app` / Rofi / `obsidian://` links (`scripts/obsidian-app.sh`): the Obsidian app. Pauses headless sync first (the app has its own Sync), or focuses the app when it's already running.
  - `obsidian-sync` (`scripts/obsidian-sync.sh`): Obsidian Sync without the app via [Obsidian Headless](https://obsidian.md/help/sync/headless) (`ob`, npm `obsidian-headless`, installed by `setup.sh` into `~/.local`). The `daemon` (started by i3) runs `ob sync --continuous` while the app is closed and stops it gracefully while the app runs, because Obsidian says the app's Sync and Headless Sync must never run at the same time on one device. `setup [vault]` (once per machine, in a terminal, app closed): backs up the vault to `~/Documents/obsidian-backup-*.tar.gz`, `ob login`, links the vault (device name `<hostname> (headless)`) with conflict strategy `conflict` (a conflict gives a separate conflict file instead of an automatic merge, which can garble text when the app was closed before uploading its last edit). Also `status`, `log` (`~/.cache/obsidian-sync.log`) and `pause`. Repeated failures (e.g. logged out) give one critical notification and back off.

- **`scripts/monitor-layout.sh`**: Multi-screen setup. Detects the connected screens; with 2 or more it puts them side by side, shows a big number on each screen and asks in the terminal which number is left / right (2 screens) or left / middle / right (3 screens). Applies the layout (preferred resolution, highest refresh rate; primary = left with 2 screens, middle with 3) and saves it as autorandr profile `main`, so it is restored at login and on replug. Called by `setup.sh` (inside the X session); re-run it any time, or find "Monitor Layout" in Rofi. `--list` only shows the detected screens. Polybar (`polybar/launch.sh`) starts a top and bottom bar on every screen; the tray sits on the primary one.
- **`scripts/menu-monitors.sh`** (`$mod+p`): Rofi screen menu; while it's open every screen shows its number in big digits. **Extend** (the saved `main` layout; arranges first when there is none for these screens), **Mirror** (autorandr's `common` profile), **Arrange screens…** (put a screen left of / right of / above / below another one) and **Rotate a screen…** (landscape, portrait counter-clockwise, portrait clockwise, upside down). Arrange and Rotate apply immediately, re-line the screens up so nothing overlaps (top-aligned side by side, left-aligned stacked) and save to the autorandr profile `main` (restored at login and replug); Polybar, workspaces and wallpaper follow via the postswitch hook. With one screen only Rotate is offered. `scripts/monitor-layout.sh` is the terminal version used by `setup.sh`.
- **`scripts/workspaces.sh`**: Assigns workspaces to screens. 2 screens side by side: workspaces 1-4 on the left screen, 5-10 on the right; 1 screen or mirrored: everything on that screen (3+ screens: not configured yet). Writes `~/.cache/theme/workspaces.conf` (included by `i3/config`), reloads i3 only when it changed and moves already open workspaces. Run by i3 at startup and by the autorandr `postswitch` hook.
- **Dunst (`dunst/dunstrc`)**:
  - Minimal notifications in the bottom-right corner just above the bottom Polybar (`offset = (10, 37)`), `2px` accent frame, `4px` corners, the active font (size 8), image thumbnails (e.g. screenshots), click to dismiss.
  - Per-app muting lives in `dunstrc.d/50-muted-apps.conf` (machine-local, managed by `scripts/menu-notifications.sh`): muted apps get a `skip_display` rule, so they never pop up but stay in the history.
  - Colors live in `~/.config/dunst/dunstrc.d/99-color-engine.conf` (symlink to `~/.cache/theme/dunst.conf`, ignored in Git via `dunst/.gitignore`) and reload via `dunstctl reload`.
- **Rofi icon pack (`rofi/app-icons.conf` + `scripts/rofi-icons.sh`)**: Minimal single-colour app icons. Every app Rofi shows gets a Material Design glyph from the active Nerd Font (chosen by icon name, then by `.desktop` category, then a default), rendered from the active font as 128px PNGs in the Color Engine `ACCENT_SOFT` colour into the `ColorEngine-Apps` icon theme (`~/.local/share/icons/ColorEngine-Apps`, set via `icon-theme` in `rofi/config.rasi`). `apply-theme.sh` re-renders them on every theme change (skipped when nothing changed). Add or change an app's glyph in `rofi/app-icons.conf`.
- **Starship prompt (`starship/starship.toml` & `starship/init.bash`)**:
  - Minimal two-line prompt: the current folder (last 4 levels, bold, in `ACCENT`), git branch (muted) and status (`ACCENT_SOFT`), the active Python virtualenv, and the duration of commands over 2s; line 2 is a `❯` in the accent (red after an error). user@host only appears as root or over SSH.
  - Commands running longer than 60s send a dunst notification when they finish.
  - `starship.toml` holds the layout only. `apply-theme.sh` writes `~/.cache/theme/starship-palette.toml` (`[palettes.color_engine]`: the Color Engine shades) and merges both into `~/.cache/theme/starship.toml` (also linked as `~/.config/starship.toml`). Starship re-reads it at every prompt, so open terminals recolor at the next command.
  - `init.bash` is sourced from `~/.bashrc` (one line, added by `setup.sh`): it sets `STARSHIP_CONFIG`, re-merges when the layout was edited, sets the terminal title to the current folder (so the i3 title bar and Polybar's `xwindow` show it), and skips Starship on the Linux console (no Nerd Font) or before the first theme was generated.
- **CLI tools (`cli/init.bash`, `cli/ripgreprc` & `cli/bat.conf`)**:
  - `init.bash` is sourced from `~/.bashrc` (one line, added by `setup.sh`) and only sets up the tools that are installed.
  - **fzf**: `Ctrl+T` files (via `fd`, `bat` preview), `Alt+C` jump to a folder (`ls` preview), `Ctrl+R` history search. Colors and layout come from `~/.cache/theme/fzf.opts` (`FZF_DEFAULT_OPTS_FILE`, generated by `apply-theme.sh`), which fzf reads at every start, so it follows theme switches immediately.
  - **`fif [text]`** ("find in files"): live `rg` search inside fzf with a `bat` preview of the matching line; Enter opens the file in Neovim on that line.
  - **ripgrep** (`RIPGREP_CONFIG_PATH`): smart case, searches hidden files but not `.git/`, long lines cut at 200 columns; paths and matches in ANSI magenta (Kitty maps it to `ACCENT`).
  - **bat** (`BAT_CONFIG_PATH`): `ansi` theme, so it uses Kitty's Color Engine palette; also used as `MANPAGER` (colored man pages) and maps the dotfiles' own formats (`.rasi`, `.theme`, `.font`).
  - **zoxide**: `z <part of a path>` jumps to a frequently used folder, `zi` picks one with fzf.
- **Rofi & Kitty**: Configured with `@import` and `include` statements pointing to `~/.cache/theme/`. Rofi (`rofi/theme.rasi`) styles both the list view and message/prompt bars (`message`, `textbox`) using Color Engine variables. Kitty (`kitty/kitty.conf`) uses the active font module's Mono variant, window padding, a full 16-color ANSI palette, and live reload via `SIGUSR1`.

### 5. Theming / Color Engine Logic
The scripts translate the 16 colors generated by Pywal (or preset themes in `~/dotfiles/themes/`) into 3 primary base variables:
- `BG` (Background, color0)
- `FG` (Foreground/Text, color15)
- `ACCENT` (Primary accent color, color4)
The central script `scripts/apply-theme.sh` computes an extended palette of derived shades in pure Bash (`BG_ALT`, `BG_VISUAL`, `FG_MUTED`, `ACCENT_SOFT`, `ACCENT_DIM`, and harmonic ANSI colors `ANSI_RED`, `ANSI_GREEN`, `ANSI_YELLOW`, `ANSI_CYAN`), writes all 15 cache files (`polybar.ini`, `kitty.conf`, `i3.conf`, `rofi.rasi`, `rofi-font.rasi`, `gtk.css`, `nvim.lua`, `herdr.toml`, `btop.theme`, `dunst.conf`, `zathurarc`, `fonts.conf`, `starship-palette.toml`, `starship.toml`, `fzf.opts`) with the active colours and the active font module, and live-reloads Kitty (`pkill -USR1 -x kitty`), btop (`pkill -USR2 -x btop`), dunst (`dunstctl reload`), i3 & Polybar (`i3-msg restart`), and Herdr (`herdr server reload-config`). Open Neovim sessions reload automatically via their filesystem watcher; Starship prompts at the next command, fzf at its next start.

### 6. Overview of Scripts
- **Naming:** every Rofi tool is `scripts/menu-<name>.sh` (`menu-theme`, `menu-wallpaper`, `menu-font`, `menu-hotkeys`, `menu-power`, `menu-clipboard`, `menu-calc`, `menu-emoji`, `menu-notifications`, `menu-wifi`, `menu-bluetooth`); `polybar-*` scripts feed the bars, everything else is a helper or a hotkey action. `setup.sh` migrates existing `i3/hotkeys.conf` files from the old names.
- **`scripts/ui-scale.sh`**: Browser-style zoom for the whole desktop: `$mod+Shift+plus` / `$mod+Shift+minus` (also keypad `+`/`-`) change the scale in 10% steps (50-250%), `$mod+Shift+BackSpace` resets to 100%. The scale is saved in `~/.cache/theme/ui-scale` and re-applied at login (`ui-scale.sh apply` in `i3/config`, after merging `~/.Xresources`). It sets `Xft.dpi` = base x scale (base = `Xft.dpi` from the machine-local `~/.Xresources`, else 96) for i3, kitty, dunst, GTK apps and Thorium, and writes `~/.cache/theme/ui-scale.rasi` / `ui-scale.ini` (DPI 96 x scale + bar height) for Rofi and Polybar, which ignore `Xft.dpi`. i3, Polybar, Rofi, dunst and open kitty windows follow immediately (i3 restarts in place; dunst silent mode is preserved); Thorium and GTK apps resize when reopened. 100% is exactly the look without scaling.
- **`scripts/lib/github-download.sh`**: Shared helpers (`gh_find_asset`, `gh_check_update`, `gh_download_verified`, `gh_install_latest`) used by `setup.sh` and `update-thorium.sh`. `gh_check_update` compares an installed version with the newest release, so Neovim and Spicetify are updated on every `setup.sh` run when a newer release exists. Every GitHub release download (Neovim, Obsidian, Thorium, Spicetify, Nerd Font modules) goes to a private temp file and is only installed when its SHA-256 matches the digest GitHub publishes; downloads without a published checksum are refused.
- **`scripts/update-thorium.sh`**: Installs/updates Thorium to the newest checksum-verified AppImage (see Thorium above). `--quiet` (used at i3 login) only sends a notification when it actually updated.
- **`setup.sh` (Master Bootstrapper)**: Installs base tools (`nala`, `curl`, `git`) and upgrades the system using the Debian installer's APT mirror only (it deliberately does not run `nala fetch`: that added extra mirrors on every run, and mixing mirrors that are out of sync breaks installs with "held broken packages"; section 2.5 removes a leftover `/etc/apt/sources.list.d/fetch.sources`), pulls or clones the latest `~/dotfiles` repository, and immediately replaces its own process (`exec bash "$DOTFILES_DIR/setup.sh"`) via the `DOTFILES_SETUP_RELOADED=1` guard so the remaining steps always execute using the newly downloaded `setup.sh`. It then installs all packages, AppImages, and CLI tools, configures the Pywal virtualenv, creates symlinks, and invokes `scripts/apply-theme.sh` for the Dracula bootstrap theme.
- **`scripts/apply-theme.sh`**: Central Color Engine that generates all theme files in `~/.cache/theme/` from `<BG> <FG> <ACCENT>` and live-reloads the desktop.
- **`scripts/menu-wallpaper.sh`**: Opens Rofi (`$mod+t`) to pick a wallpaper from `~/dotfiles/wallpapers/`, sets it via `feh`, extracts colors with `wal`, and passes them to `apply-theme.sh`.
- **`scripts/menu-theme.sh`**: Opens Rofi (`$mod+Shift+w`) to pick a preset theme from `~/dotfiles/themes/` (`dracula.theme`, `tokyonight.theme`) and passes its colors to `apply-theme.sh`.
- **`scripts/toggle-modkey.sh`**: Toggles the `$mod` key in `i3/hotkeys.conf` between `Mod1` (Alt) and `Mod4` (Super/Win) and reloads i3.
- **`scripts/menu-hotkeys.sh`**: Interactive English Rofi menu (`$mod+m`) displaying a clean 2-column overview (`Key │ Short description`) of all i3 hotkeys in `i3/hotkeys.conf`. Selecting an action opens a live X11 key-capture popup (`libX11`) where pressing any single key or modifier+key combination immediately rebinds the hotkey (with conflict swap/overwrite prompts, `i3 -C` syntax validation, automatic rollback on error, and live reload; pressing `Esc` always exits the menu).
- **`scripts/lock.sh`**: Syncs the active `feh` wallpaper (`~/.fehbg`) to the `ColorEngine` LightDM theme directory, ensures `light-locker` is running, and locks the session via `light-locker-command -l` (with `dm-tool lock` fallback). Symlinked to `~/.local/bin/lock` and bound to `$mod+Shift+x`.
- **`scripts/lockscreen-setup.sh`**: One-time (sudo) provisioning of the LightDM side: creates user-owned `/usr/share/themes/ColorEngine` & `/usr/share/icons/ColorEngine`, writes `/etc/lightdm/lightdm-gtk-greeter.conf` and `lightdm.conf.d/50-color-engine.conf`, installs the font system-wide, then re-applies the active palette from `~/.cache/theme/current.theme`. Called by `setup.sh` (section 8.5). The generated `gtk.css` defines `@lightdm-gtk-greeter-override-defaults` so the greeter's built-in colors drop to FALLBACK priority and the Color Engine styling wins.
- **`scripts/screenshot.sh`**: Area screenshot (`$mod+Shift+s`): drag a rectangle or click a window (`maim -s`, selection highlighted in the active `ACCENT` color), saves `~/Pictures/screenshot_<date>_<time>.png`, copies it to the clipboard as `image/png` via `xclip`, and shows a `notify-send` notification. `Esc`/right-click cancels.
- **`scripts/menu-font.sh`**: Rofi font picker (`$mod+Shift+f`). Lists all font modules (installed fonts previewed in their own typeface, active one checked), downloads a missing font first (only needed for a module added after `setup.sh` ran), stores the choice in `~/.cache/theme/current.font` and re-runs `apply-theme.sh`, which writes the font into every generated config: Polybar (`[fonts]` in `polybar.ini`, used by `font-0`/`font-1`), i3 (`i3.conf`), Rofi (`rofi-font.rasi`), dunst (`dunst.conf`, dunst is restarted on a font change), Kitty (`kitty.conf`, Mono variant), GTK/Thunar/LightDM (`gtk.css` + `settings.ini`), Zathura, Spotify (Spicetify CSS), Obsidian (`obsidian.css`), fontconfig (web pages) and the Rofi icons. The tracked configs contain no font names.
- **`scripts/lib/fonts.sh`**: Font module helpers (`font_ids`, `font_load`, `font_active`, `font_set_active`, `font_is_installed`, `font_install`, `font_file`) used by `setup.sh`, `apply-theme.sh`, `menu-font.sh` and `rofi-icons.sh`.
- **`scripts/menu-wifi.sh`**: Rofi network menu (left-click on the Polybar network icon): nearby Wi-Fi networks by signal strength (connected one checked, lock icon = secured), connect (password prompt only for new secured networks; a failed attempt removes the broken profile), disconnect/forget, Wi-Fi on/off, rescan, hidden network, and shortcuts to `nm-connection-editor` (GTK, themed via `gtk.css`) and `nmtui`.
- **`scripts/menu-bluetooth.sh`**: Rofi Bluetooth menu (left-click on the Polybar Bluetooth icon; right-click toggles power): paired devices with type icon (connected first, checked, with battery level when reported); pick one to connect (or disconnect when connected) or forget it. *Pair new device…* scans ~10 s and pairs, trusts and connects the chosen device (PIN prompts come from `blueman-applet`, kept running as pairing agent). Also power on/off and `blueman-manager` for advanced settings.
- **`scripts/obsidian-colorengine.sh`**: Copies the ColorEngine plugin (`obsidian/colorengine/`) into every vault in `~/.config/obsidian/obsidian.json` (or the vault passed as `$1`) and enables it (when Obsidian is running: enable it under *Settings > Community plugins*). Not run by `setup.sh`: vaults arrive later through Sync, together with the plugin.
- **`scripts/spotify-restart.sh`**: Run by `apply-theme.sh` after Spicetify applied a new theme (Spotify only loads it at startup): restarts Spotify and, when it was playing, continues the same track at the same position (Spotify's restored session, or the track's URI via `playerctl open`, then `playerctl position`). Runs in the background; a few seconds of silence.
- **`scripts/menu-power.sh`**: Rofi power menu (`$mod+Shift+e`): lock, suspend, log out, reboot, shut down (the last three ask for confirmation).
- **`scripts/menu-clipboard.sh`**: Clipboard history. `daemon` (started by i3) keeps the last 50 text entries in `$XDG_RUNTIME_DIR/clipboard-history` (RAM only, mode `700`, wiped at logout, images skipped); `menu` (`$mod+c`) re-copies an entry or clears the history. Note: copied passwords stay in the history until cleared or logout.
- **`scripts/menu-calc.sh`**: Rofi calculator on `qalc` (`$mod+equal`): units, currencies and percentages; select the result to copy it.
- **`scripts/menu-emoji.sh`**: Rofi emoji picker (`$mod+Shift+period`) built from `/usr/share/unicode/emoji/emoji-test.txt` (cached in `~/.cache/emoji-list.txt`); types the emoji via `xdotool` and copies it.
- **`scripts/battery-notify.sh`**: Low-battery warnings via dunst at 20% (normal) and 10%/5% (critical) while discharging; started by i3 and exits immediately on machines without a battery.
- **`scripts/lock-suspend.sh`**: Suspends the machine after it has been locked for 30 minutes (`LOCK_SUSPEND_AFTER` seconds, default `1800`). Locked = light-locker screensaver active and the X session inactive (greeter on the seat). Started once by i3 (single instance via `flock`); after resume the timer restarts. Bare metal only: in a VM it exits immediately. `lock-suspend.sh --status` shows machine type, lock state and whether the watcher runs. `setup.sh` installs `/etc/polkit-1/rules.d/50-lock-suspend.rules` on bare metal so the (inactive) locked session may suspend without a password.
- **`scripts/lib/machine.sh`**: `machine_is_vm` / `machine_type` helpers (systemd-detect-virt, with CPU `hypervisor` flag and DMI fallback); used by `lock-suspend.sh` and `setup.sh`.
- **`scripts/desktop-entries.sh`**: Makes every dotfiles tool findable in Rofi's app launcher (`$mod+space`): writes `~/.local/share/applications/colorengine-*.desktop` entries (Font Picker, Theme Selector, Wallpaper Theme, Hotkey Menu, Switch Mod Key, Clipboard History, Calculator, Emoji Picker, Screenshot, Notifications, Power Menu, Lock Screen) with English + Dutch search keywords (e.g. `font`/`lettertype`, `theme`/`kleuren`) and their hotkey in the comment. Icons are the `colorengine-*` glyphs in `rofi/app-icons.conf`. It also hides launcher noise via a local `NoDisplay=true` copy: ImageMagick's `display` GUI ("ImageMagick (color depth=q16)"); the package stays installed because Pywal needs it. Called by `setup.sh`.
- **`scripts/default-apps.sh`**: Sets default applications via `xdg-mime` (web → Thorium, PDF/EPUB → Zathura, images → imv, audio/video → mpv, folders → Thunar); only for apps that are installed.
- **`scripts/menu-notifications.sh`**: Notification manager. `toggle` (`$mod+n`) switches silent mode (dunst pause: notifications are held and shown when silent mode is turned off); `menu` (`$mod+Shift+n`) opens a Rofi menu to toggle silent mode, re-show the last notification, clear the history, and mute/unmute any app that has sent a notification (or type an app name to mute it); `status` feeds the Polybar bell module.
- **`scripts/calendar.sh`**: Polybar clock click handler. Toggles a `yad` GTK calendar (themed by `gtk.css`, with week numbers and previous/next month arrows) in the top-right corner of the focused monitor. Click the clock again or press `Esc` to close it.
- **`scripts/polybar-disk.sh`**, **`scripts/polybar-memory.sh`** & **`scripts/polybar-ip.sh`**: Disk usage, RAM usage and local IPv4 helpers for the bottom Polybar (kept as scripts so `config.ini` needs no escaping).
- **`scripts/polybar-gpu.sh`**: Multi-vendor GPU utilization helper for the bottom Polybar (`NVIDIA`, `AMD`, and `Intel` via DRM sysfs), with automatic VM vs. baremetal fallback detection.
